## Status

## Evidence and lower-ID transfer test

Atlus's original-edition publisher manual describes pulling blocks out to create one-height stairs, edge-contact suspension, live loss of bottom rows and Normal-mode undo. Original PS3 player writing corroborates the first stage and explicitly confirms English-release Normal undo. `ACT-009` covers pushing but explicitly excludes pulling; `ACT-044` is a general retained-simulation rewind, not reversal of a recent local move. `SYS-084` falls an unsupported multi-cell body after one discrete input and cannot describe independently supported tower blocks. Existing authored-support-loss genes describe a finite scene transition, not continual row removal while the player rearranges blocks. The one-block height limit independently constrains manipulation. The local view joins support and danger cues without proving exact unseen timing. Written accounts disagree about dark fixed blocks in Stage 1, so no gene for that feature is assigned.

## Disposition

Accept six bounded genes without reassigning earlier games. Reuse direct movement (`ACT-008`), adjacent push (`ACT-009`), collapsing-route exit (`OBJ-231`) and real-time input during forced progression (`TIM-003`). The Xbox 360 publisher manual supports the common original rules, but not PS3 button mapping; the exact PS3 revision, board layout, undo/time interaction and collapse cadence are not claimed. Optional score, retries, later special blocks and *Full Body* Remix stay outside this packet.
