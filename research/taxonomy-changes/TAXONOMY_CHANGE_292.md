# Taxonomy Change 292 — Dispatch first-shift responder scheduling

- Proposal status: Accepted
- Claim status: Observation
- Evidence quality: Corroborated
- Confidence: High
- Date: 2026-11-19.
- Trigger: [GAME-0545](../../knowledge/games/a-f/dispatch.md),
  the full PS5 release's first real Episode 2 Z-Team shift.

| Addition | Reviewed boundary | Counterexample |
| --- | --- | --- |
| `ACT-743` | Commit available heroes to a current call's allowed slots. | `ACT-036` assigns a continuing behavioural profession, while `ACT-651` places actors on tactical starting panels. |
| `SYS-1577` | Evaluate effective group attributes and admitted interventions for a call result. | `SYS-801` requires disclosed dice plus modifiers; visual fit is not a disclosed universal outcome formula. |
| `SYS-1578` | Travel, work, return and rest delay a responder's reuse. | A weapon cooldown does not temporarily remove an actor from the dispatch roster. |
| `SYS-1579` | Apply an injury penalty, second-injury sidelining and eligible power exceptions. | A cosmetic wound or a combat health bar has different state transitions. |
| `SYS-1580` | Discover and apply identity-specific powers under dispatch conditions. | Generic XP progression alone cannot model solo travel, form changes, illusion partners or injury immunity. |
| `SYS-1581` | A directional build prompt changes the traversable hack graph. | `ACT-733` extends an aimed grid route; it does not navigate a separate avatar and revisit reconfigurable nodes. |
| `INF-526` | Read live calls, proposed five-axis fit and actor availability together. | `INF-123` supplies an individual profile, without the incident map and proposed team comparison. |
| `OBJ-302` | Reach the shift review through its required closing intervention, retaining non-perfect calls. | A perfect achievement and a single incident endpoint differ from a completed multi-call shift. |

Twelve definitions transfer unchanged, including symbolic directional entry,
password validation, XP and point spending, authored responses, live input,
expiring opportunities and mission evaluation. Slot caps parameterise dispatch;
no separate constraint is added merely for a different team size. The complete
20-gene partition was manually reviewed in this unit. Existing definitions,
signatures and verified combinations remain unchanged.
