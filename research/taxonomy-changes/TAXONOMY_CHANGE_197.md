# Taxonomy Change 197: first N64 summit guardian and Star

## Status

- Proposal status: Accepted
- Claim status: Observation
- Evidence quality: Corroborated
- Confidence: High
- Date: 2026-09-30.
- Trigger: `GAME-0460`, original *Super Mario 64* first Bob-omb Battlefield Star.
- Scope: four new Active definitions among twelve uses; eight unchanged reuses. No earlier signature, combination or published revision is changed.

## Evidence and boundary tests

The [game ledger](../../knowledge/games/s-z/super-mario-64.md) separates the original European Nintendo booklet's shared controls from the pinned US original-game code and an independent written first-Star route. No cartridge was executed and regional software parity is not asserted.

- `ACT-610` is a deliberate following-camera command during direct world-actor control. Existing `ACT-095` changes rule-bearing geometry through projection and `ACT-609` selects fixed vehicle viewpoints; neither fits the Lakitu reframe.
- `ACT-611` creates a held phase for a live guardian before its directional release. `ACT-048` is an inert free object and `ACT-297` is a fighting throw without this carried phase.
- `SYS-1211` evaluates the throw's landed summit position and finite guardian health. An off-summit throw returns without credit. It is not generic damage, ordinary ring-out or the player's separate Star contact.
- `OBJ-262` requires both encounter completion and subsequent contact with the spawned Power Star. Boss defeat alone does not end the first-Star packet. `SYS-037` applies only to nonterminal coin contact here; it explicitly excludes a destination contact that itself completes the stage.

## Reuse and disposition

The remaining eight uses fit earlier movement, body physics, contact pickup, autonomous hazard, health, local HUD, local view and real-time genes without rewriting their definitions. Three valid landings is a parameter, not a gene. Optional shortcuts, other Stars, the DS remake and later Bowser encounter are excluded, not merged by title familiarity. All four new Ukrainian definitions were reviewed in the same game unit.
