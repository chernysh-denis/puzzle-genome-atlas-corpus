# Taxonomy Change 271 — Wave Race 64 buoy power and race limits

- Proposal status: Accepted
- Claim status: Observation
- Evidence quality: Corroborated
- Confidence: High
- Date: 2026-11-17.
- Trigger: [GAME-0524](../../knowledge/games/s-z/wave-race-64.md),
  original North American N64 Normal Championship Sunny Beach.

| Addition | Boundary | Counterexample |
| --- | --- | --- |
| `ACT-720` | A separate input softens bounce while crossing a moveable wave. | The R slide changes the steering line and ordinary body lean balances the craft. |
| `SYS-1501` | Craft pitch and bounce follow the active supporting water surface. | An ordinary static ramp or cosmetic wave does not couple the craft to a moving support. |
| `SYS-1502` | Correct-side markers add a capped speed tier and misses clear the whole tier. | `SYS-765` charges a spendable acceleration reserve through manoeuvres. |
| `SYS-1503` | Place points enter a cumulative cut before the next round. | `SYS-895` settles the complete cup into a trophy after the last race. |
| `SYS-1504` | The timed launch sets the same power tier that buoys subsequently change. | `SYS-1302` is a bounded launch acceleration advantage. |
| `CON-803` | Wrong-side and missed markers count toward disqualification across all laps. | `CON-438` makes every required checkpoint obligatory for a finish. |
| `CON-804` | Leaving the perimeter starts a time window in which steering back saves the run. | `SYS-1424` actively returns a vehicle to the track. |
| `INF-507` | The displayed required side differs from the perimeter return cue. | A generic waypoint indicates where to go without requiring one passing side. |
| `INF-508` | The current power tier and cumulative miss count are presented independently. | A single selected charge display cannot tell the player whether past mistakes remain. |

Six existing definitions transfer unchanged. No verified combination is
a proper subset. Earlier records and signatures are preserved.
