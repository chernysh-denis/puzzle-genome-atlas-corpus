# Taxonomy Change 288 — Galley House archive address

- Proposal status: Accepted
- Claim status: Observation
- Evidence quality: Corroborated
- Confidence: High
- Date: 2026-11-18.
- Trigger: [The Incident at Galley House](../../knowledge/games/s-z/the-incident-at-galley-house.md),
  IGH-002–IGH-005.

## Decision

- Add `ACT-738` for composing and explicitly submitting one multipart
  evidence address.
- Add `SYS-1563` for exact lookup of a fixed evidence scene by its typed
  address. The scene does not represent a list of search results.
- Add `CON-814` for requiring registration of a location on a separate
  control before including it in an archive address.

Free-text transcript matching, spatial entry into a memory and a fixed
deduction answer panel retain their own boundaries. Reuse `INF-012` for
the resulting evidence, independently of how the lookup was expressed.
