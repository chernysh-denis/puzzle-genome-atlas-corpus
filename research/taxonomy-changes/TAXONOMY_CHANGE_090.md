## Problem

The selected opening joins fixed-camera tank-relative traversal, six carried
slots, one Sword Key retained across three compatible locks and a manual save
that consumes one Ink Ribbon. The selection hypothesis incorrectly described
both the exact mode label and per-door key consumption, so every candidate had
to be tested against the original booklet and complete lower-ID vocabulary.

## Accepted change

- Correct the selected label from `Original mode` to the exact
  `STANDARD (original version)`.
- Reuse `ACT-341` plus `CON-296` for one authority retained across compatible
  locks until its final discard; do not add or apply a per-door key-consumption
  boundary.
- Reuse `CON-621` for a designated typewriter whose existing
  `optional per-save consumable` parameter is one Ink Ribbon.
- Add explicit Resident Evil: Director's Cut carrier evidence to all twenty-one
  reused boundaries without changing their definitions.

## Complete lower-ID transfer test

- `SYS-063` consumes a key for each locked fixture. The Sword Key instead
  remains after the first and second admitted locks and becomes discardable
  only when no compatible scoped lock remains, so this boundary is rejected.
- `CON-621` already admits a per-save consumable while preserving the atomic
  requirement that the actor use an eligible designated world fixture. A new
  Ink-Ribbon gene would duplicate a parameter rather than isolate an operation.
- `ACT-183` requires a player-committed reload. The selected handgun reloads
  automatically when empty and another clip exists, so weapon legality stays
  in `CON-285` and no reload action is admitted.
- `OBJ-026` already admits making one target location traversably connected,
  crossing it and verifying persistence after arrival. No chapter settlement
  or successor handoff supports `OBJ-155`.
