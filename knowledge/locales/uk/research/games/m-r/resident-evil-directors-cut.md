# GAME-0348 — "Resident Evil: Director’s Cut"

Перевірений український дослідницький огляд. Стабільні ідентифікатори
та межі механік відповідають канонічному англійському запису.

- Статус аналізу: `перевірено`
- Дата перегляду: `2026-09-21`

## Механічний профіль

Chris рухається відносно власного напрямку крізь кімнати з фіксованими ракурсами, тримає handgun, ammunition, Sword Key та Ink Ribbon у шести місцях спорядження й бачить лише місцеву небезпеку. Один Sword Key лишається після перших дверей, відкриває три сумісні замки й зникає тільки після остаточного запиту на відкидання. Typewriter приймає одну Ink Ribbon, записує відкритий маршрут у файл memory card, а повторне завантаження перевіряє збереження стану.

## Опис механіки

Chris має лише шість місць у спорядженні, рухається відносно власного напрямку й бачить небезпеку крізь фіксовані ракурси. Один Sword Key послідовно відкриває три двері, а Ink Ribbon витрачається на typewriter, щоб зберегти відкритий маршрут. Це реконструкція за джерелами, не гра на PlayStation.

## Межа аналізу

Перший північноамериканський англомовний диск Resident Evil: Director's Cut для PlayStation, SLUS-00551, випуск 1997-09-30; нова гра, точний режим STANDARD (original version), Chris Redfield, від першого звичайного керування в Dining Room до перезавантаженого файлу в західній save room після відкриття трьох сумісних дверей Sword Key і переходу в L Passage. Фіксований маршрут: оглянути першого zombie й повернутися до Main Hall; отримати або підібрати handgun та Ink Ribbon; дістатися західної save room, зустріти Rebecca й узяти Sword Key; відкрити двері Keeper's Bedroom, Piano Bar і вихід Art Room у L Passage; лише після останнього сумісного замка погодитися відкинути ключ; перейти в L Passage; повернутися до typewriter; витратити одну Ink Ribbon на свіжий файл memory card; вийти, завантажити файл і перевірити відкритий маршрут та відсутність вичерпаного ключа. Включено tank-relative рух, біг лише вперед, фіксовані ракурси, прицілювання й постріл, автоматичне перезарядження порожнього handgun за наявності clip, живе переслідування й шкоду, один condition pool, шість місць спорядження, підіймання та equip, одну authority для трьох замків, мапу відвіданих кімнат, typewriter, Ink Ribbon і branchable load. Виключено bundled demo, TRAINING, ADVANCED, Jill, item box, healing, puzzle-item combining, shotgun, crests, piano puzzle, Hunters, Yawn, Plant 42, Tyrant, подальший mansion/laboratory route, endings, rankings, Dual Shock Version, інші регіони, порти, remakes, randomizer, чити, моди й аудіовізуальний аналіз.

## Статус безпосереднього проходження

Безпосередньої гри не проводили: диск, PlayStation, контролер, memory card, ROM, емулятор, збереження, скриншот, відео й аудіо не використовували. Точний англомовний посібник встановлює серійний номер, STANDARD (original version), керування, handgun, шість місць Chris, condition, map, typewriter, Ink Ribbon і правила memory card; перевірений запис диска та три письмові маршрути Chris підтверджують початковий handgun, Rebecca, Sword Key, три замки й остаточне відкидання. Локальний контроль лише реконструює заявлені стани, не запускає програму й не виводить точні значення шкоди, здоров’я ворогів, часу чи колізій.
