# GAME-0448 — Temple Run

Перевірений український дослідницький огляд. Стабільні ідентифікатори
та межі механік відповідають канонічному англійському запису.

- Статус аналізу: `перевірено`
- Дата перегляду: `2026-09-28`

## Механічний профіль

Безупинно біжи храмовим шляхом: вчасно проводь пальцем для поворотів, стрибків і підкатів, нахиляй телефон до монет та набирай очки до першої фатальної помилки

## Опис механіки

У класичній Temple Run герой сам біжить храмовим шляхом. Проведи пальцем, щоб повернути на розі, перестрибнути чи проковзнути під перешкодою; нахиляй телефон убік, щоб рухатися вздовж рядів монет. Якщо герой спотикається, переслідувачі наближаються, а фатальна помилка завершує спробу й фіксує рахунок. Правила оригінальної версії для iPhone 2011 року відтворено за свідченнями творців і тогочасними оглядами, без власного проходження.

## Межа аналізу

Одиниця аналізу — одна нова партія оригінальної Temple Run від Imangi для iPhone, випущеної в серпні 2011 року, без куплених поліпшень чи відновлення. Точну стартову збірку й номер її пізнішого оновлення не досліджували; межі визначають тогочасні описи безпосередніх гравців і ретроспектива творців. Початок — узяти ідола, після чого герой автоматично біжить, а демонічні мавпи переслідують його. На видимому повороті проведи пальцем ліворуч чи праворуч, біля перешкоди — угору для стрибка або вниз для підкату. Нахил телефона окремо зміщує героя поперек доріжки, зокрема до лінії монет; нахил не замінює повороту. Попереду видно лише найближчу частину шляху, а подальший маршрут змінюється між спробами; конкретний алгоритм утворення маршруту не встановлено. Спотикання може підпустити переслідувачів без негайного завершення, натомість фатальне падіння, зіткнення чи захоплення завершує партію, після чого можна оглянути накопичений рахунок. Відстань, монети й допустимі бонуси впливають на поточний рахунок; локальна мета — набрати якнайбільше очок до першої остаточної поразки, а не дістатися кінця храму. Збирання звичайних монет включено, але витрачання їх після партії — ні. Виключено Temple Run 2, Temple Run+, інші схеми керування для Android і браузера, сучасні випробування, пізніші події та рекламу, покупки, поліпшення, відродження, персонажів, таблиці рекордів, поступ завдань і множника між спробами й точні числові формули. Окремий майбутній аналіз міг би розглянути куплені здібності, відновлення чи прогрес множника у визначеній ревізії оригінальної гри. Правила першої версії відтворено за свідченнями творців та тогочасними оглядами, не за власним проходженням.

## Статус безпосереднього проходження

Оригінальний застосунок iPhone, виконувану збірку, запис дотиків, скриншоти, відео й завершену партію не досліджували; у гру не грали. Розповідь засновника-розробника від першої особи пояснює керування, неможливість зупинки й переслідування; огляд із власним досвідом 2011 року описує партію та змінний маршрут. Точну ревізію, послідовність перешкод, допуски зіткнень, тривалість відновлення і формулу рахунку не виміряно. Ілюстрація оригінальна, не знімок гри.
