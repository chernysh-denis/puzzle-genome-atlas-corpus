# GAME-0064 — SET

Перевірений український дослідницький огляд. Стабільні ідентифікатори
та межі механік відповідають канонічному англійському запису.

- Статус аналізу: `перевірено`
- Дата перегляду: `2026-08-13`

## Механічний профіль

Пошук трійки за незалежним відношенням ознак

## Опис механіки

SET у межах одного відтворюваного сольного поля — детермінована головоломка про пошук трійки карт за одним точним відношенням. Стандартна колода містить усі 81 унікальні комбінації чотирьох ознак: кількості символів, кольору, форми й заповнення, по три значення кожної. На столі одночасно видно 12 карт. Гравець вибирає рівно три різні карти, після чого кожна ознака перевіряється незалежно: її три значення мають бути або всі однакові, або всі різні. Якщо хоча б одна ознака має розподіл два плюс один, уся трійка не є SET, навіть коли решта ознак виконують правило. Корисна стратегія — взяти дві карти й вивести єдині потрібні ознаки третьої: однакова пара вимагає того самого значення, різна пара — третього відсутнього. Зафіксоване поле для цього запису містить рівно один SET серед усіх 220 можливих трійок, у позиціях 3, 6 і 11. Усі дані видимі, випадковості після розкладки й таймера немає. Змагальний викрик, заміна карт, додавання трьох карт за відсутності SET, штраф, уся колода та варіанти до цієї межі не входять.

## Межа аналізу

Офіційна базова сольна процедура SET у межах одного відтворюваного видимого поля з 12 карт, закодованого з повної стандартної колоди з 81 карти. Включено чотири незалежні ознаки — кількість, колір, форму й заповнення — по три значення кожної; одну унікальну карту для кожного кортежу ознак; одночасну видимість усіх 12 карт; вибір рівно трьох різних карт; прийняття лише тоді, коли для кожної ознаки окремо три значення або всі однакові, або всі різні; збереження одного знайденого SET; самостійний пошук і негайну перевірку правила. Зафіксоване поле має рівно один SET у позиціях 3, 6 і 11. Виключено змагальний викрик і строк підбору; інших гравців, штрафи й порівняння рахунку; подальший добір замін; додавання трьох карт за відсутності SET; вичерпання колоди; Easy Start, Daily Puzzle, SET Junior, CO-OP SET та інші варіанти; швидкість пошуку, доступність кольорів і оформлення.

## Статус безпосереднього проходження

Безпосередню партію не проводили. Поточна сторінка видавця й архівна офіційна інструкція встановлюють склад колоди, логічне правило та сольний режим. Mathematical Association of America і два математичні дослідження незалежно підтверджують колоду 3⁴ та покоординатну умову. Локальний повний перебір перевірив усі C(12,3) = 220 трійок контрольного поля й знайшов рівно одну допустиму.
