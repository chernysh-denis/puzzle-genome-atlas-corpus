# COMB-0233 — Finite checkpoint recovery across a cumulative driving stage

- Claim status: `Observation`
- Evidence quality: `Corroborated`
- Confidence: `High`
- Corpus role: verified interaction pattern
- Novelty assessment: no exact combination-set duplicate among 232 registered

## Combination gene set

`ACT-290 + ACT-350 + SYS-515 + SYS-516 + SYS-519 + SYS-746 + CON-577 + INF-205 + INF-286 + OBJ-146`

This is a strict ten-gene subset of the twenty-one-gene Need for Speed: The Run
genome. Car choice, difficulty configuration, traffic, nitrous, story-order
gates, low-level speed/route guidance and real-time scheduling remain outside
the distinctive relation.

## Decision structure

The player drives against an autonomous field and can spend a finite recovery
unit to restore the last passed checkpoint while the current event remains
unfinished. Because the last unit instead fails the event, recovery risk must
be read beside the current target. Several valid event finishes retain rank
progress, and only the completed stage exposes its successor.

## Combination match boundary

Generic racing, a free restart or one rewarded finish is insufficient. A
supporting ruleset must debit a difficulty-fixed checkpoint recovery stock whose
last spend is terminal, expose that stock beside continuing route-rank progress
and carry several rival-event results into one stage successor.

## Novelty and variants

- Forza Horizon 6 shares car/rival/course settlement, but its scoped opening
  uses optional Rewind and Festival Points rather than a final-reset failure and
  one cumulative cross-country position.
- BeamNG.drive shares an assigned-car recovery command, but its Road Master
  recovery has no disclosed finite stock whose last unit fails the attempt, and
  one Time Trial result is its terminal.
- Need for Speed Underground has a retained rival-race reward, but no multi-
  event route rank or difficulty-sized checkpoint-reset budget.
