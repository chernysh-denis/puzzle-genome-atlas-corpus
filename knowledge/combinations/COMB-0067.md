## Decision structure

The system serially presents one complete ordered target without leaving a
persistent symbolic record. During the following input phase, the player
reproduces its cue identities in exact ordinal order. Each input is checked at
its position: the first mismatch ends the attempt, while exact completion
retains the whole target, appends one cue and returns to automatic presentation
of the longer sequence.

## Combination match boundary

A generic memory task or pattern copy is insufficient. The complete target
must be presented transiently in sequence, input must occur in a distinct
response phase, each symbol must be adjudicated by ordinal identity, and a
successful target must be replayed with exactly one appended cue. Persistent
reference images, unordered recall, editable whole-answer submission,
aggregate partial credit and replacement by an unrelated next sequence fall
outside the boundary.
