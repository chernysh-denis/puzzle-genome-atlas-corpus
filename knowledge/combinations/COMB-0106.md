## Decision structure

The player submits a broad free-text term and receives a stable chronological
result set truncated to its earliest five records. Playing one returned fixed
clip exposes additional spoken vocabulary. The player chooses a rarer term and
submits it as a new query; the same transcript matcher now returns a later clip
that the broad result counted but could not make viewable.

## Combination match boundary

A conventional paginated search is insufficient, as is filtering an already
visible list. The archive must match player-authored terms against immutable
evidence text, expose only the stable earliest subset of a broad result, allow
one returned record to be played, and let vocabulary from that evidence drive
a refined query that surfaces a previously capped record.
