This five-gene set is a proper subset of both supporting genomes. It captures
the shared decision loop without requiring a particular fixed-grid
representation, terminal identity rule, number of routes, coverage condition,
region-clue grammar or invalid-answer feedback.

## Decision structure

The player inspects a fully visible finite instance and, without a forced
clock, traces one ordered topology-contiguous simple path from its fixed
origin. The chosen route is a component of a complete constraint-satisfying
answer, so local edge choices must preserve global feasibility before the path
is committed.

All three games also share `CON-001`, but generic finite occupancy capacity is
background instance structure rather than a causal part of tracing and
satisfying a simple path.

## Combination match boundary

A game does not instantiate this combination merely by drawing a line or
solving a visible grid. The player must directly trace a fixed-origin simple
declared-topology path, the path must contribute to a complete constraint
assignment, the current instance must be inspectable and no time-driven state
may force decisions. Automatic route finding, freehand drawing without graph
continuity, real-time route editing and paths pursued only for score fail the
boundary.
