## Decision structure

The player adds a clue spread to an inspectable diegetic manual and learns that
a familiar directional control also forms a symbolic alphabet. At one addressed
patterned seal, the player enters its exact ordered cardinal trace quickly
enough to preserve the unfinished buffer. The complete match opens a persistent
route to the next location. Because the system checks the sequence rather than
manual ownership, prior knowledge can satisfy the same gate.

## Combination match boundary

A collectible hint plus a locked door is insufficient. The reference must
communicate a pre-existing symbolic use of directional input; the player must
enter an exact ordered code while addressing one world seal; inactivity must
be able to clear an unfinished attempt without changing the world; and the
exact code must open the same route even when the clue page is not owned.
