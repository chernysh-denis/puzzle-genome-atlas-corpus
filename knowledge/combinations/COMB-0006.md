- Evidence quality: `Corroborated`

## Combination gene set

- Actions: `ACT-008`, `ACT-009`
- Constraints: `CON-011`, `CON-012`, `CON-013`
- Objective: `OBJ-004`
- Time: `TIM-002`

This seven-gene set is a proper subset of the supporting nine-gene genome.
Fixed board capacity and fully visible current state remain part of the Sokoban
genome but are not required to identify this interaction.

## Decision structure

The player self-pacedly navigates one agent to the required side of a crate and
pushes that crate through exclusively occupied floor cells toward an
interchangeable target arrangement. Because objects cannot be pulled, a legal
push may preserve walking moves while permanently eliminating every completion
path.

## Analysed games

- [`GAME-0006` — Sokoban](../games/s-z/sokoban.md)

Patrick's Parabox does not support this full seven-gene combination because
multi-box chain pushes violate `CON-012` and recursive containment violates the
whole-world fixed-capacity condition `CON-001`. The smaller shared core is
recorded as [`COMB-0036`](COMB-0036.md).

## Combination match boundary

A puzzle does not instantiate this combination merely because an avatar moves
boxes. The player must navigate the pushing agent, move only one adjacent object
from behind into a free destination, lack a pull operation, pursue a specified
object-target configuration and face legal non-terminal states from which that
objective is unreachable.
