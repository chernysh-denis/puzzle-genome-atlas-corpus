## Decision structure

The player chooses a replacement class and one seed cell. The system changes
the seed's complete maximal same-class connected component and coalesces it
with every adjacent component already carrying the replacement class. Each
resolved move therefore contracts the visible component-adjacency graph.
Repeating the operation must reduce that graph to one player-chosen class.

## Combination match boundary

A game does not instantiate this interaction merely because colours change or
matching objects merge. One player command must identify a current connected
component through a seed, replace the complete component's class, automatically
coalesce newly adjacent equal-class components and pursue a single-class field.
Single-cell painting, shaped overlay, deletion with collapse and expansion
from one permanently fixed origin fall outside the boundary.
