## Decision structure

The player self-pacedly assigns binary cell states. Each visible clue gives the
ordered lengths but not positions of filled runs, and every assignment must
satisfy the intersecting row and column descriptions simultaneously until the
entire grid is determined.

## Combination match boundary

A binary picture puzzle does not instantiate this combination merely because
it uses a grid. It must disclose ordered run lengths for both orthogonal axes,
couple each cell to both line constraints and require a complete binary
assignment satisfying all of those descriptions.
