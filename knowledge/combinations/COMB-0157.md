## Decision structure

The squad reads a timed mission map, keys and spatially deploys typed support,
manages alarm escalation and a shared return budget under universal friendly
fire, completes the main objective before orbital support ends, and then
separately settles survivors, samples and shared campaign impact.

- [`GAME-0159` — Helldivers 2](../games/g-l/helldivers-2.md)

## Combination match boundary

An extraction shooter is insufficient: the scoped loop must combine ordered
symbolic support input with spatial deployment, survivor-triggered return from
a shared squad budget, allied damage validity, a hard support horizon and a
debrief that distinguishes objective success, extraction assets and a shared
campaign contribution.

ARC Raiders calls extraction but lacks coded orbital support and community-war
settlement. Apex Legends has survivor-mediated return but no universal
friendly-fire contract or main-objective-before-extraction result. Battlefield
6 combines squad combat and gadgets without the same mission/operation split.
