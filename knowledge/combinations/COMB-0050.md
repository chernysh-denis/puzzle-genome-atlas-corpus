# COMB-0050 — Bounded prepared attack queue with ordered activation

- Claim status: `Confirmed`
- Evidence quality: `Corroborated`
- Confidence: `High`

## Combination gene set

- Actions: `ACT-065`, `ACT-066`
- System Behaviour: `SYS-090`
- Constraints: `CON-096`, `CON-097`
- Time: `TIM-001`

The six-gene set is a proper subset of the supporting 15-gene genome. Movement,
facing, swap, hostile response, board geometry, current-state visibility,
hostile preview and clearance remain outside because they do not define the
prepared player-attack execution relation.

## Decision structure

The player spends turns inserting ready attacks into a small editable queue,
orders them for interaction, then activates the whole list as one action. The
system resolves attacks sequentially against the changing intermediate state;
used attacks become unavailable until later turn boundaries recharge them.

## Analysed games

- [`GAME-0050` — Shogun Showdown](../games/s-z/shogun-showdown.md)

## Combination match boundary

Holding several attacks is insufficient. Queue membership and order must be
editable before a distinct activation command, capacity must be bounded, the
complete prepared list must resolve automatically in order as one player
action and used attacks must recover through discrete turn advancement. A
card played for immediate effect, a machine program tested in a separate run or
a tactical phase containing several independently resolved abilities fails.

## Relation to hostile-intent combinations

`COMB-0014` / `COMB-0047` concern complete hostile attacks committed before a
bounded player phase; `COMB-0048` concerns a revisable tactical forecast.
`COMB-0050` instead describes preparation and automatic resolution of the
player's own attacks. Shogun Showdown's action-by-action hostile response is a
separate system relation and is deliberately outside this combination.
