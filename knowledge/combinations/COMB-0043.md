## Decision structure

The player orients a persistent body-attached tool and uses it to displace an
elongated object. Contact direction selects axial slide or lateral roll, which
determines the currently exposed surface. Grill contact records processing per
identified face, while repeating one face is terminal. The player must process
every face exactly once and restore the required tool-bearing pose through
discrete input-resolution cycles.

## Combination match boundary

A push puzzle does not instantiate this combination merely by moving an object
over goals. It must make body-attached tool orientation decision-relevant,
resolve an elongated object's displacement differently by contact axis,
preserve independently processed physical faces, forbid processing any face
twice and require the complete face set plus a return pose. Static target
occupancy, cosmetic object rotation and freely repeatable triggers fall outside
the boundary.
