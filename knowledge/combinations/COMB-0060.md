## Decision structure

The player presses one visible trigger whose linked hooks and lines immediately
withdraw along fixed swept paths. A withdrawal succeeds and permanently reduces
the active set only when every blocking mechanism has already disappeared;
otherwise collision rejects and resets the attempt. Solving the level therefore
requires reading the visible obstruction graph and activating its currently
unblocked nodes in a valid dependency order until no hook remains.

## Combination match boundary

A game does not instantiate this interaction merely because switches activate
remote objects or because pieces are removed. One addressed trigger must start
automatic withdrawal of one or several linked line mechanisms; still-present
geometry must block the complete swept withdrawal; successful triggers must
monotonically remove their mechanisms; and completion must exhaust the declared
set through a dependency-valid order. Static toggles, player-dragged deletion,
route construction and simultaneous vehicle scheduling fall outside the
boundary.
