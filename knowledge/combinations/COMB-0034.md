## Combination gene set

- Action: `ACT-044`
- System Behaviour: `SYS-045`
- Information: `INF-001`
- Time: `TIM-003`, `TIM-007`

This five-gene set is a proper subset of both supporting genomes. It captures
their shared reversible live-simulation contract without claiming that avatar
platforming and temporal immunity are equivalent to population routing,
physical-device editing or path projection.

## Decision structure

Autonomous agents continue to move on a visible real-time simulation while the
player can intervene. After observing an unwanted result, the player rewinds
the authoritative world to an earlier state and resumes a replacement branch.
The combination guarantees live motion, visible state and branch replacement;
the action used after rewind and the reason the new outcome differs remain
game-specific.

## Combination match boundary

A game does not instantiate this combination through undo or replay alone.
One or more agents must move autonomously while real-time input is accepted;
the current state must be visible; and the player must be able to restore a
previously lived simulation state and resume an alternate continuation. A
turn-based undo, full restart, locked machine run or random-access prospective
command editor falls outside the boundary.

Pikmin 4 confirms that rewind restoration may select retained checkpoints
rather than scrub continuously. Restoration granularity is a parameter so long
as the selected prior state becomes authoritative and new play replaces the
discarded continuation.
