This six-gene set is a proper subset of the supporting eight-gene Lights Out

## Decision structure

The player presses one addressed binary cell. The system simultaneously
inverts that cell and its existing orthogonal neighbours. Every press is its
own inverse, press order does not affect the final state, and global binary
invariants restrict which visible configurations can reach the specified
target. The player composes these local reversible transformations until every
cell matches the all-off configuration.

## Combination match boundary

A board does not instantiate this combination merely because it contains
switches or reversible moves. The player must address one binary cell, the
system must toggle its complete declared neighbourhood atomically, the
primitive action must be structurally self-inverse, global invariants must
exclude some otherwise representable states, and the terminal predicate must
be a specified complete configuration. HOOK activates linked mechanisms but
removes them irreversibly; KAMI replaces a selected component's class rather
than applying a fixed local involution.
