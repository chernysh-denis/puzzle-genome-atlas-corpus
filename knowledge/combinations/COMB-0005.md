## Decision structure

Visible immutable givens restrict overlapping units. The player self-pacedly
assigns symbols to open positions, using the all-different coverage rule to
eliminate candidates and derive forced values, until every position is assigned
and every unit satisfies the same domain constraint.

## Combination match boundary

A puzzle does not instantiate this combination merely because it uses a grid or
numbers. Some assignments must be immutable givens, the player must assign one
symbol to each remaining position, overlapping units must each contain the
complete symbol domain exactly once, and success must require a complete valid
assignment without time-driven state change.
