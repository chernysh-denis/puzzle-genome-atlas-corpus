## Decision structure

Isaac enters a seed-generated floor graph, aims tears and positions bombs while
live enemies and hazards continue, clears locked rooms, combines sampled item
effects into one health-bounded run build, defeats each floor boss and either
reaches the first Mom ending or loses the entire transient build on death.

## Combination match boundary

A procedural dungeon or action game alone is insufficient. The ruleset must
combine a seed-generated graph of authored rooms, clearance-locked local exits,
direct real-time projectile combat, cumulative run-only item effects, finite
heart survival, boss-gated floor descent and terminal loss of the current build
while persistent unlock state remains.

Slay the Spire shares a seeded disposable run, health and random offers but uses
turn-based card encounters on a disclosed act-node map. Path of Exile 2 shares
real-time combat and build composition but retains the character build after
Softcore death and resets only the current campaign area.
