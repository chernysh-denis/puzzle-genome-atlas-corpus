## Decision structure

Every offensive, evasive and defensive option is bought from one continuous
reserve that refills only while it is not being spent, so each exchange is an
allocation rather than a set of independent cooldowns. A reversible bind fixes
the character's facing to one selected hostile and reorganises movement around
it. Ordinary death returns the character to the last rested checkpoint, which
also repopulates the enemies between it and the objective, and leaves the
carried currency in a single mark that a second death destroys. The route ends
only when a sealed mandatory guardian, whose remaining health is continuously
exposed, is carried through a threshold transformation and its opened threshold
is crossed.

## Combination match boundary

Generic melee combat, a stamina bar, a checkpoint or a two-phase boss alone is
insufficient. A supporting ruleset must price attack, evasion, sprint and guard
from the same recovering reserve, withdraw the defensive options when that
reserve is exhausted, offer a reversible player-selected facing bind, convert
death into a checkpoint return plus one replaceable currency mark, and settle
its route through a sealed guardian that changes attack set at a remaining-health
threshold inside the same encounter.

## Novelty and variants

- Black Myth: Wukong shares the authored route, real-time melee, checkpoint
  rest and mandatory guardian, but spends a separate focus resource, selects
  staff stances and carries no death-currency mark.
- Elden Ring shares the recoverable mark, the single-mark rule and checkpoint
  rest, but places them inside an open traversal scope with a mount, spirit
  summons, levelling and flask allocation rather than one bounded linear route.
- STAR WARS Jedi: Fallen Order shares authored traversal and checkpoint
  recovery but answers attacks through a timed deflection and a separate force
  resource rather than one shared reserve.
- Class, weapon, shield, area, guardian, item and exact quantity names remain
  parameters.
