- Claim status: `Confirmed`

## Combination gene set

- Action: `ACT-008`, `ACT-044`
- Information: `INF-001`
- Time: `TIM-003`, `TIM-007`

This five-gene set is a proper subset of every supporting genome. It requires
the direct-navigation and reversible-history relation while omitting each
game's distinct puzzle objects, automatic agents, objectives and rewind
granularity.

## Decision structure

The player navigates one persistent avatar through a currently visible world
whose relevant state continues on a live simulation clock. After observing a
bad route, fall or intervention, the player can restore an already lived state,
stop at the chosen earlier point and navigate or intervene differently so the
new continuation replaces the abandoned branch.

## Combination match boundary

A game does not instantiate this core merely because it has an undo button,
checkpoints, direct movement or a replay. It must combine direct local avatar
navigation, visible current state, live simulation progression and retained
history that the player can restore before making a different intervention.
Automatic-agent-only rewind, discrete edit undo, whole-level restart and a
non-branchable replay fail the boundary.

`COMB-0041` complements rather than replaces `COMB-0034`. The latter requires
continuous autonomous locomotion under branchable rewind; this record requires
direct controllable-agent navigation. Braid and Pikmin 4 support both relations,
while Tin Hearts supports only the autonomous core and Viewfinder only the
direct-navigation core.
