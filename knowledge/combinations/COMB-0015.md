## Decision structure

One global directional input shifts every eligible element by only one cell,
automatically merges base complements or equal higher ranks, then inserts a
preview-bounded random successor into one changed line at the trailing edge.
The player therefore controls both collisions and the candidate set from which
the system chooses the insertion position.

## Combination match boundary

A slide-and-merge game does not instantiate this combination merely because a
direction moves many tiles. Movement must be bounded to one step per command,
merge compatibility must follow the ruleset's declared pair relation,
and the post-move successor must be category-previewed and restricted to a
changed line on the trailing edge.
