## Decision structure

The player independently marks cell boundaries. Unmarked orthogonal contacts
induce connected cell components; every resulting component must contain
exactly one visible centre dot and be closed under a half-turn about that dot.
Completion requires the selected edges to be precisely the boundaries between
the resulting valid regions, without an internal extraneous edge.

## Combination match boundary

A puzzle does not instantiate this combination merely by partitioning a board
or displaying symmetric shapes. It must let the player persistently select
fixed cell boundaries, use one centre marker per resulting component and
require every component to be 180-degree rotationally symmetric about its own
marker.
