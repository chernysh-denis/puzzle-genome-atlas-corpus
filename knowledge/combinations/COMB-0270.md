# COMB-0270 — Grade a bounded activity and expose its contributing categories

- Claim status: `Pattern`
- Evidence quality: `Corroborated`
- Confidence: `High`
- Corpus role: verified interaction pattern
- Novelty assessment: no exact duplicate among 269 prior combinations; this is
  the first portable interaction in which a bounded activity computes and
  records an aggregate performance grade and its terminal report exposes both
  the contributing categories and that aggregate evaluation.

## Combination gene set

`SYS-822 + INF-299`

This is a strict two-gene subset of both the fourteen-gene Cuphead genome and
the eighteen-gene DAVE THE DIVER genome. Their actions, activity-specific
failure states and evaluated category vocabularies remain outside the
combination because they vary; the interaction begins when completed
performance is classified and made inspectable in one terminal report.

## Decision structure

The player completes one bounded activity. At settlement, the system reads
declared properties of how that activity was performed and records an aggregate
grade separately from the completion or closure itself. The same result surface
then exposes the contributing category values and the aggregate, so the player
can attribute one grade to particular performance decisions rather than receive
an unexplained rank.

## Analysed games

## Combination match boundary

A completion flag, numeric score, reward tier or grade alone is insufficient.
A supporting ruleset must settle a finite activity by evaluating declared
performance properties, record an aggregate evaluation alongside the activity
result, and expose both the contributing categories and aggregate in the
terminal report. Category names, weights, scale, activity type and later reward
effects are parameters.

## Novelty and variants

- Cuphead evaluates time, remaining health, parries, special-resource use and
  skill level after one boss level, then exposes them with the aggregate grade.
- DAVE THE DIVER evaluates the first restaurant service and exposes its sales or
  service categories with the aggregate grade at closing.
- Dishonored exposes mission-conduct categories and aggregate Chaos through
  `INF-299`, but its scoped system does not compute a graded activity result and
  therefore does not support the complete combination.
- A reward chest mapped from an Ops score is outside this relation because it
  adds a reward-admission transition that neither carrier requires.
