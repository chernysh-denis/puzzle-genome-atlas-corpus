## Decision structure

The player continuously edits one persistent free-form answer. Every revealed
predicate is reevaluated after each edit and remains jointly binding. Only an
all-valid current state permanently adds the next authored predicate to the
same answer, so a locally useful edit can reopen an earlier failure while the
later rule stack remains visible.

## Combination match boundary

A fixed constraint puzzle or a sequence of replaced questions is insufficient.
One mutable answer must survive across a growing authored rule sequence; all
revealed rules must remain active and visibly revalidate; satisfying the entire
current conjunction must reveal the next rule. Submit-only guesses, independent
answer fields and player-authored rule syntax remain outside the boundary.
