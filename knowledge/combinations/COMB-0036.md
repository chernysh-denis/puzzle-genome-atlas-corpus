This seven-gene set is a proper subset of both supporting genomes. It captures
the visible deterministic push-only target-reconstruction core without
requiring one fixed board, a single-object push limit, chain propagation,
recursive containment or nested-view context.

## Decision structure

The player navigates a persistent agent through exclusive visible occupancy
and changes the target arrangement by pushing an adjacent object from behind.
Because pulling is unavailable, a legal push can preserve ordinary movement
while making the target configuration unreachable. Inputs remain self-paced,
and success depends on reconstructing the declared occupancy rather than score
or survival.

## Combination match boundary

A game does not instantiate this combination merely by moving blocks onto
goals. One locally navigated agent must physically push adjacent objects under
exclusive occupancy; a legal push must be capable of producing a non-terminal
objective deadlock; current state must be visible; the declared arrangement
must be the completion objective; and no running clock may mutate puzzle state
between inputs. Direct piece relocation, pulling, automatic flow and
score-only block placement fall outside the boundary.
