## Decision structure

One fresh Live character follows quest markers, moves and fights in real time,
and converts experience into retained levels. Completed quest stages and level
20 jointly expose one compatible class offer. Confirming Warrior changes the
persistent class while retaining the same server character and closes the
packet only after that state can be inspected.

## Combination match boundary

Generic MMORPG combat, levelling or a class-selection screen is insufficient.
A supporting ruleset must make a persistent level threshold and authored quest
jointly gate one exclusive first class transfer, retain it on the same live
character and use it as the bounded terminal.
