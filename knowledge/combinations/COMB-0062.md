## Decision structure

The player self-pacedly assigns one bounded positive value to every editable
cell. Each visible directional clue names one fixed line and its exact required
sum; cells shared by intersecting lines contribute the same value to each of
them. Completion requires one total assignment that satisfies every declared
line equation simultaneously.

## Combination match boundary

A number-placement puzzle does not instantiate this interaction merely because
it uses a grid or arithmetic. It must expose exact sums for fixed lines, let
one assigned cell participate in several intersecting equations and require a
complete bounded-value assignment satisfying all of those equations together.
All-different units, ordered run descriptions, concealed-neighbour counts and
independent arithmetic questions fall outside the boundary.
