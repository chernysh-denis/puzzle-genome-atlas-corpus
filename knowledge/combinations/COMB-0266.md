# COMB-0266 — Two-regime encounter closed by an earned reward-free release

- Claim status: `Strong Pattern`
- Evidence quality: `Corroborated`
- Confidence: `High`
- Corpus role: verified interaction pattern
- Novelty assessment: no exact duplicate among 265 prior combinations; this is
  the corpus's first interaction in which one encounter alternates strictly
  between a discrete command phase and a continuous evasion phase, and in which
  ending that encounter peacefully is a legality earned from the specific
  opponent rather than a chance, a resource or a capability the player already
  owns.

## Combination gene set

`ACT-019 + ACT-445 + SYS-813 + SYS-814 + SYS-815 + CON-611 + INF-325 + OBJ-162 + TIM-001 + TIM-003`

This is a strict ten-gene subset of the seventeen-gene Undertale genome.
Overworld movement, authored-object interaction, item consumption, the health
pool, checkpoint restore, general option legality and the personal-state display
remain outside the distinctive interaction, because they describe how the run is
sustained rather than what makes the two phases and the earned release answer
each other. The graded attack input is outside it for a different reason:
`TAXONOMY_CHANGE_031` removed that Action from the genome, because the declared
route never executes it, so the destructive option enters this pattern as one of
the declared commands `ACT-019` selects among rather than as a verb of its own.

## Decision structure

An encounter runs in strict alternation. In the command phase the player picks
one declared option against one opponent and the system resolves it fully before
accepting another, and destroying the opponent is always among those options, so
the peaceful close is refused power rather than absent power. In the
opponent's phase nothing but continuous steering is accepted: a small token is
confined to a bounded board the opponent fills with shapes, and avoiding them is
a spatial problem rather than a timing one. Each opponent declares its own
non-damaging interactions and a private condition over them, and satisfying that
condition is the only thing that makes the release option legal. The interface
marks that the release has become possible without saying why. Committing it
closes the encounter exactly as a defeat would while paying none of a defeat's
rewards, so the player's competence at one half of the encounter cannot
substitute for the other, and the peaceful close is something earned rather than
chosen.

## Combination match boundary

A turn-based menu, a bullet-dodge minigame, a spare option or a pacifist
achievement alone is insufficient. A supporting ruleset must alternate strictly
between a discrete command phase and a continuous evasion phase that never
accept each other's inputs, keep a destructive option available throughout,
accumulate opponent-specific non-damaging interactions into a private release
condition, gate the release command on that condition as a legality rather than
a probability, mark the resulting eligibility without disclosing its rule, and
close the encounter on release while withholding the rewards a defeat would pay.

## Novelty and variants

- Clair Obscur: Expedition 33 shares the command selection, both time genes and
  the option-legality boundary, but its real-time element is a timed defensive
  input inside an otherwise discrete turn, and its objective is to incapacitate
  the hostile set.
- Dead Space (2023 remake) shares the traversal-and-survival substrate but
  resolves every encounter by destroying opponents in continuous time.
- Pokémon Legends: Z-A shares removing an opponent without defeating it, but
  through a probabilistic capture into owned storage rather than an earned
  legality that pays nothing.
- Monster, interaction wording, board geometry and exact quantity names remain
  parameters.
