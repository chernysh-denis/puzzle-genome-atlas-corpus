# Plain-language gene explanations

This directory contains a reviewed, game-scoped presentation layer for people
who do not already speak the Atlas taxonomy. It does not rename a canonical
gene, change its boundary or alter a game genome.

Each entry provides:

- a short human-facing label;
- a one-sentence explanation of the mechanic;
- one concrete example inside the reviewed game scope;
- a link back to the unchanged canonical gene ID and label in the web UI.

The registry now covers 285 defining-gene uses across 59 reviewed games: the
initial five-game pilot plus six balanced nine-game expansions. Explanations are
scoped to a game because the same reusable gene can have a different clearest
example in another game. Expansion requires manual review; text must not be
generated from the canonical definition at runtime.
