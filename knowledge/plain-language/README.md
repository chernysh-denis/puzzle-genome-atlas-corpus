# Plain-language gene explanations

This directory contains a reviewed, game-scoped presentation layer for people
who do not already speak the Atlas taxonomy. It does not rename a canonical
gene, change its boundary or alter a game genome.

Each entry provides:

- a short human-facing label;
- a one-sentence explanation of the mechanic;
- one concrete example inside the reviewed game scope;
- a link back to the unchanged canonical gene ID and label in the web UI.

Explanations are scoped to a game because the same reusable gene can have a
different clearest example in another game. Expansion requires manual review;
text must not be generated from the canonical definition at runtime.

Defining genes remain the primary, fully expanded reading surface. Structural
genes use shorter explanation cards, while supporting genes use compact
disclosures with an optional in-play example so long genomes remain scannable.
